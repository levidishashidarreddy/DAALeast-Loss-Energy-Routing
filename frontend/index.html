DAA Algorithm Architecture

Core theoretical characteristics of the Single-Source Shortest Path (SSSP) algorithms implemented in C.

Greedy Strategy

Dijkstra's Algorithm

Binary Min-Heap & Decrease-Key
Time Complexity O((V + E) log V)
Space Complexity O(V + E)

Greedily finalizes unvisited nodes with minimal tentative distance. Extremely fast for large non-negative microgrids, but assumes non-decreasing distances and fails with negative rebate lines.

Dynamic Programming

Bellman-Ford Algorithm

Iterative Edge Relaxation
Time Complexity O(V · E)
Space Complexity O(V + E)

Relaxes all E edges across V − 1 passes with early-exit convergence. Supports negative energy feed-in rebates and flags unbounded arbitrage loops on the V-th pass.

View Faculty Viva Voce Q&A & Theoretical Proofs
Why does Dijkstra fail on negative-weight edges?

Dijkstra assumes that adding an edge can never reduce path distance. Once a node is extracted from the min-heap, it is finalized. A later negative feed-in rebate could lower total cost, but Dijkstra never revisits finalized nodes.

Why are V − 1 relaxation passes sufficient in Bellman-Ford?

In any simple directed graph without cycles, the longest shortest path contains at most V − 1 edges. Each pass guarantees discovering shortest paths with one additional hop.

What is an energy arbitrage loop, and how is it detected?

A closed loop with net negative weight (∑ w < 0) where rebates exceed losses. Bellman-Ford detects this during its V-th pass if distance can still be relaxed.

What constitutes Bellman-Ford's adversarial worst case?

A reverse-ordered line graph where edge propagation occurs only by a single node per pass, disabling early exit and forcing all V − 1 passes (quadratic runtime).
